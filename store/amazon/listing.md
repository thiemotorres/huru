# Amazon Appstore – Huru

Everything needed to submit Huru in the [Amazon Developer Console](https://developer.amazon.com/apps-and-games/console/apps/list.html).
Graphics in this folder are generated by `python3 tools/store_assets.py`.

## 0. Before you start

- Amazon developer account (free) – the console asks for payout and tax info even for free apps.
- The **Amazon APK**: artifact `huru-amazon-apk` of the release workflow for the version you submit (built with `-Pstore=amazon`: no Ko-fi QR). Download with `gh run download <run-id> -n huru-amazon-apk -D store/amazon/` (APKs here are git-ignored).
- Repository must be public (privacy policy link) – it is.

## 3. Description

**Short description:**
A clean, ad-free IPTV player for your own Xtream Codes subscription. Huru provides no channels or content.

**Long description:**
Huru is a calm, fast and ad-free player for IPTV services that use the Xtream Codes API. Sign in with the details from your own provider – or try the built-in demo with free, legal test content – and watch live TV, movies and series, built for the Fire TV remote from the ground up.

• Live TV with a programme guide right in the channel list
• Fast zapping with Up/Down and an info overlay
• Starts straight into the last channel you watched
• Favourites and hideable categories
• Movies and series with search, "Continue watching" and automatic next episode
• Several sources: add and switch between logins
• No ads, no tracking, no account

Important: Huru is only a player. It does not provide, sell or recommend any channels, playlists, movies or series. You need your own subscription from a provider that is licensed to distribute its content.

**Product feature bullets:**
- Programme guide (EPG) right in the channel list
- Fast zapping and last-channel start
- Movies & series with resume, search and next episode
- Several sources, favourites and hideable categories
- No ads, no tracking – try the free demo in one tap

**Keywords:** iptv, xtream, player, live tv, epg, tv guide

## 5. Content rating

Answer "None" for violence, sexual content, profanity, drugs, alcohol, gambling and so on – the app itself contains none of it.
Questions about **unrestricted access to content / streaming media from the internet**: answer **yes** – users play whatever their own provider offers. Expect a "Guidance suggested"/mature-style rating; that is normal for players and browsers.
Collects personal information: **no** (credentials stay on the device, see the privacy policy). Ads: **no**. Location: **no**.

## 6. Binary file (APK)

- Upload `huru-<version>-amazon.apk`.
- **Device support:** Fire TV devices only; deselect phones/tablets if the console pre-selects them. Fire TV models running **Vega OS** (e.g. Fire TV Stick 4K Select) cannot run Android apps and are excluded automatically.
- **Language support:** English, German.
- **Export compliance:** the app uses only standard HTTPS – confirm.
- **App signing:** let Amazon sign the app (default). Appstore installs will then have a different signature than GitHub releases – users cannot update one with the other.

## 7. Testing instructions (paste into the console)

> Huru is a player for the user's own Xtream Codes subscription. For testing, select "Try the demo" on the first screen: it connects to our demo server with legal content only (Blender open movies under Creative Commons and public HLS test streams). Manual login: server `https://huru-demo.feto.dev`, username `demo`, password `demo`.
> Remote: Up/Down zaps between channels, OK shows the info overlay, Play/Pause pauses, long-press OK adds a favourite. Movies and series: Left/Right seek, Play/Pause pauses.

## 8. After submitting

- Review usually takes a few days. Amazon actively removes piracy-related IPTV apps – the description and the demo make clear Huru is only a player.
- If rejected, the email lists the failed test cases; fix, bump the version (`git tag vX.Y.Z`) and upload the new Amazon APK.
