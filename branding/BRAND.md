# Huru – Brand

**Idea:** A screen with the sun rising and a gull flying: TV with a sense of space, free of ads and clutter. *Huru* means "free" in Swahili.

## Files

| File | Use |
|---|---|
| `icon.svg` | App icon (plum tile) |
| `icon-small.svg` | App icon up to 72 px – without the gull |
| `mark.svg` | Symbol without the tile |
| `mark-mono-plum.svg`, `mark-mono-white.svg` | Single colour (stamps, print, dark surfaces) |
| `wordmark.svg`, `wordmark-cream.svg` | Wordmark on its own |
| `lockup.svg`, `lockup-reversed.svg` | Tile + wordmark, horizontal (light / dark) |
| `stacked.svg` | Tile above wordmark |
| `banner.svg` | Fire TV banner 320×180 (in the app as `drawable-xhdpi/banner.png`) |

## Colours

| Name | HEX | RGB | Role |
|---|---|---|---|
| Plum | `#3B1F3A` | 59 31 58 | Tile, text on light |
| Coral | `#FF6B4A` | 255 107 74 | Screen, accent in the app |
| Coral dark | `#E5502F` | 229 80 47 | Horizon |
| Mustard | `#FFC23D` | 255 194 61 | Sun |
| Cream | `#FFF4E6` | 255 244 230 | Gull, text on dark |
| Night | `#1E1520` | 30 21 32 | App background |

## Typeface

Wordmark set in **Figtree ExtraBold** (SIL Open Font License 1.1), converted to outlines – the font does not need to be installed.

## Rules

- **Clear space:** at least the height of the sun on every side (≈ 20 % of the tile width).
- **Minimum sizes:** icon with gull from 96 px, below that `icon-small.svg`; wordmark from 24 px height.
- **Backgrounds:** lockup on cream/white, `lockup-reversed.svg` on plum/night. The tile works on both.
- **Don't:** swap colours, move or rescale elements, add shadows or gradients, set the wordmark in another typeface, or use the gull alone as the logo.
